*[ABI]: Application binary interface. The rules compiled code follows to call other compiled code, so that two builds can work together.
*[API]: Application programming interface. The functions and classes a library offers to code that uses it.
*[CI]: Continuous integration. The builds and tests GitHub runs on pushes and pull requests to the main branch.
*[CPU]: Central processing unit. The processor that runs a program.
*[DLPack]: An open in-memory tensor format that array libraries use to share an array's memory without copying it.
*[GIL]: Global interpreter lock. The lock that lets only one thread of a CPython process run Python code at a time.
*[OS]: Operating system.
*[PID]: Process identifier. The number the operating system gives a running process.
*[POSIX]: Portable Operating System Interface. The standard that Linux and other Unix-like systems follow.
*[RAII]: Resource acquisition is initialization. A C++ style where an object releases what it holds when it goes out of scope.
*[UTC]: Coordinated Universal Time. The time standard that offsets such as +02:00 are measured from.
