# CLAUDE.md

`sharedbox` gives Python processes a dict that lives in shared memory. The
container is C++ (Boost.Interprocess) exposed to Python with nanobind. Only
`SharedDict` exists today.

## Repository layout

|   |-- shareddict.{hpp,cpp}   nanobind class SharedDict, value encoding, module definition

  regenerated stub whenever the bound API changes.
- `utils.py` is plain Python. `SharedDict.recommend_sizing()` imports it at
  call time.

## Memory layout

One Boost `managed_shared_memory` segment per `SharedDict`, named after the
`name` argument, `size` bytes (default 128 MiB). `create=True` opens the
segment if it exists and creates it otherwise; `create=False` opens only and
fails if missing.

Two named objects inside the segment:

- `"__map"`: `boost::container::map<ByteVec, ByteVec>`, ordered by `memcmp`
  on the bytes, shorter key first on a tie. `ByteVec` is a `char` vector
  allocated from the segment.
- `"__mutexes"`: array of `max_keys` `interprocess_mutex`.

`max_keys` is the number of lock stripes, not a limit on entries. A key picks
its mutex by 64-bit FNV-1a hash modulo `max_keys`. Opening an existing segment
with a larger `max_keys` than it was created with raises `RuntimeError`.
`keys()`, `values()`, `items()` lock every stripe in index order. `len()`
reads the map size without locking.

Stripes serialize access to one key, but all keys share one tree. Two
processes inserting or deleting keys that hash to different stripes change the
same tree at the same time, and no lock covers that. A lookup can also walk
the tree while another stripe's insert rebalances it. Only a workload with no
concurrent inserts or deletes is free of this race.

### Entry encoding

- Key: the `str` encoded as UTF-8, stored raw. Only `str` keys are accepted.
- Value: one marker byte, then the payload.
  - `0x00`: `pickle.dumps(value, protocol=HIGHEST_PROTOCOL)`.
  - `0x01`: numpy array, little-endian fields:
    `u32 dtype_len | dtype str ("<f8") | u32 ndim | u64 shape[ndim] | u64 data_len | raw data`.
    Supported dtype kinds: int, uint, float, complex, bool. Byte order is
    always written as `<`.
  - Any other first byte: read as pickle with no marker (older format).
- Reading a numpy value returns a new array (a copy), never a view into the
  segment.

### Lifecycle

- `close()` sets a flag. Later calls raise `RuntimeError`. The segment stays
  mapped until the object is garbage collected.
- `unlink()` removes the named segment. It raises unless `close()` was called
  first. Only the creating process should call it.
- A segment that is never unlinked survives the process (on Linux it stays in
  `/dev/shm`). The next `SharedDict` with the same name and `create=True`
  sees the old data. Tests use fixed names, so a crashed run can leave data
  that the next run picks up.

## Build

scikit-build-core drives CMake, which needs:

- `VCPKG_ROOT` set; CMake stops without it.
- Boost from vcpkg: `vcpkg install boost-interprocess`. Header only.
- A `.venv` in the repo root: `CMakeLists.txt` sets `Python_ROOT_DIR` to it.
- C++17 compiler (MSVC or GCC). macOS is not supported.

The version comes from git tags through setuptools-scm, written to
`src/sharedbox/_version.py` (ignored by git).

```sh
uv sync --dev          # creates .venv, builds and installs the extension
```

Rebuild after any C++ change; `uv sync` does not notice edited sources by
itself, so use `uv sync --dev --reinstall-package sharedbox`.

## Tests

```sh
uv run pytest                    # current interpreter
uv run pytest tests/test_numpy_support.py -k simple
nox -s tests                     # Python 3.10 to 3.13, needs nox (uv tool install nox)
```

CI (`.github/workflows/ci.yaml`) builds wheels with cibuildwheel for CPython
3.10 to 3.13 on Windows and Linux (manylinux, musllinux), runs pytest against
each wheel, and publishes to PyPI on a GitHub release. Tests are skipped on
musllinux because they fail at random there. Docker runs with
`--shm-size=1g`, so keep test segments under that.

## Usage

```python
import multiprocessing as mp
from sharedbox import SharedDict

def worker(name):
    d = SharedDict(name, create=False)
    d["from_worker"] = [1, 2, 3]
    d.close()

if __name__ == "__main__":
    d = SharedDict("demo", {"a": 1}, size=16 * 1024 * 1024, max_keys=256)
    p = mp.Process(target=worker, args=("demo",))
    p.start(); p.join()
    print(d["from_worker"])
    d.close()
    d.unlink()
```

Values can be any picklable object; numpy arrays skip pickle. Every read
returns a copy, so mutating a list or nested dict you got back does not change
what is stored. Assign the whole value again.
