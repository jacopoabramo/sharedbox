`SharedBox.metadata` and `SharedStream.metadata`: a box or stream keeps
metadata, JSON-like values stored as CBOR in its segment, in numbered
versions. `Scale.create("scale", metadata={"unit": "kg"})` and
`SharedStream.create(Reading, capacity=8, metadata={"unit": "kg"})` store
version 1, `SharedBox.add_metadata` and `SharedSendStream.add_metadata` add
the next, and `metadata`, `metadata_version` and `metadata_version_of` read
them, a map as a read-only mapping and a list as a tuple. A stream version
applies from the next item sent, and `SharedReceiveStream.metadata` and
`metadata_version` give the version of the item the reader received last.
`BoxEvents.metadata` is emitted with each new version of a box. The class
keywords `metadata_capacity` and `metadata_versions`, and the
`SharedStream.create` keywords of the same names, size the room for versions.
`class Scale(SharedBox[Calibration])` and `metadata_type=Calibration` on
`SharedStream.create` and `attach` give the metadata's type to type
checkers. `MetadataFullError` and `MetadataGoneError` are new errors. Box
layout 3.2 and stream layout 1.4 hold the metadata after the record or the
description table; `box.hpp` and `stream.hpp` add `metadata_head`,
`read_metadata`, `add_metadata` and `status::metadata_full`, and
`sharedbox_c.h` adds `sbx_metadata_head`, `sbx_read_metadata`,
`sbx_add_metadata` and `SBX_E_METADATA_FULL`. `sharedbox` 0.7.0 and earlier
cannot open a stream created with metadata or a `metadata_capacity`.
