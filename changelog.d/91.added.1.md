`SharedBox.metadata`: a box keeps metadata, JSON-like values stored as CBOR
in its segment, in numbered versions. `Scale.create(name, metadata={"unit":
"kg"})` stores version 1, `SharedBox.add_metadata` adds the next from any
process, and `metadata`, `metadata_version` and `metadata_version_of` read
them, a map as a read-only mapping and a list as a tuple.
`BoxEvents.metadata` is emitted with each new version. The class keywords
`metadata_capacity` and `metadata_versions` size the room for versions, and
`class Scale(SharedBox[Calibration])` gives the metadata's type to type
checkers.
