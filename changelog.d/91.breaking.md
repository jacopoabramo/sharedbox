`SharedBox` reserves the names `metadata`, `metadata_version`
and `metadata_version_of`: a field or `InitVar` with one of
them raises `TypeError` when the class is defined. Rename the field:

```python
# 0.7
class Parcel(SharedBox):
    metadata: Annotated[str, Capacity(64)] = ""

# 0.8
class Parcel(SharedBox):
    label: Annotated[str, Capacity(64)] = ""
```

See
[How to migrate from 0.7](https://jacopoabramo.github.io/sharedbox/how-to/migrate-from-0.7/).
